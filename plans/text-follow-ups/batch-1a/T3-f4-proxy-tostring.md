# T3: F4 proxy `toString` (typescript-pro)

**Goal:** every ElkGraph element prints like the JVM when it is an EMF proxy, proven by `graph.json` rows recorded
first.

## Context

Generated ElkGraph impls start `toString()` with `if (eIsProxy()) return super.toString();` (9 classes, D5:
ElkBendPoint, ElkEdge, ElkEdgeSection, ElkGraphElement, ElkLabel, ElkNode, ElkPort, ElkShape,
ElkPropertyToValueMapEntry `Impl`, e.g. `$ELK_SOURCE_DIR/plugins/org.eclipse.elk.graph/src/org/eclipse/elk/graph/impl/ElkNodeImpl.java:363`).
EMF `BasicEObjectImpl.toString` appends ` (eProxyURI: <uri>)` for a proxy. The TS `BasicEObjectImpl.toString`
(`src/emf/ecore/impl/BasicEObjectImpl.ts:265-275`) returns only the class name (elkgraph-model D10), and the TS impls
document the arm as not ported (e.g. `src/graph/impl/ElkEdgeImpl.ts:23-25`).

## Steps

1. Scenarios: one proxy of each of the 9 types (`eSetProxyURI`), plus an edge whose source is a proxy node; record
   `toString()` with `@<hex>` stripped (D5). Regenerate; existing rows must be unchanged (stop 9). Replay: red.
2. `BasicEObjectImpl.toString`: append ` (eProxyURI: ${uri})` when `eIsProxy()`; add the 9 arms (`super.toString()`
   of `BasicEObjectImpl`, as Java), each with its `@see`. Update the "not ported" comments.

## Acceptance criteria

- Given a proxy of each of the 9 types, when `toString()` is called, then it equals the JVM row, e.g.
  `org.eclipse.elk.graph.impl.ElkNodeImpl (eProxyURI: <uri>)`.
- Given an edge whose source is a proxy node, when `edge.toString()` is called, then it matches the JVM row.
- Given any non-proxy element, then its `toString` and every existing `graph.json` row replay unchanged.
- Given the commit, then typecheck, the colocated tests and complexity pass.
