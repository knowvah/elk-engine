# Text-sizing seam: mission brief (roadmap row 10, issue #41)

## Objective

Add the first text-sizing oracle patch, `0003-alg.test-pluggable-label-text-measurer.patch`. At the pin, ELK measures text in
one place only: the JUnit framework's `TestConfiguration.computeLabelSize`, which uses AWT font metrics. The patch makes that
measurement pluggable behind a `TextMeasurer`. The default stays AWT, and a `fixed` mode gives a platform-independent
measure of `[length × 6, 12]`. The paired TS seam goes into the framework's port in `test/helpers/`. With both sides in fixed
mode, show that TS and the oracle size every label-bearing model alike. The FX8 snapshot stays the reference for the default
path (the #52 ruling on #41). No ELK class is ported, and no `src/` surface changes.

Exit (issue #41 "done when", plus the maintainer's comment on it):

- the oracle is rebuilt through `tools/oracle/build.sh` with patch 0003, and the default behaviour is proven unchanged (TX7);
- goldens are regenerated by script with the patch id in `_meta.json`, and every changed ref is journaled (TX8);
- TS and the oracle sizes agree on label-bearing models: up to 137 vendored models (deduplicated by content) for sizes and layouts (committed ref), 759 corpus
  models for sizes (local), and the runner suites have equal outcomes in fixed mode (TX6);
- the reference platform (macOS arm64, JDK 21.0.1) is pinned in `docs/conformance.md` next to the FX8 notes, and every
  recording and measurement is made on it and journaled with the patch id (#52);
- the seam's relation to the snapshot is recorded: "both" (TX3);
- the queue gates pass; there is one squashed commit on the base; `plans/roadmap.md` gains
  `## Revision <end date> (text-sizing-seam)`.

**Not in this mission:** a font model; #58's four missing snapshot texts; any change to the snapshot or to `src/` exports.
