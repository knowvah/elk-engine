## Interface contract (output, consumed by T4–T8)
Each file: `{ "jdk": string, <section>: rows[] }`, encoding as today (double/float = 16-hex
`doubleToRawLongBits`, floats widened first; `long` = decimal string; `int` = JSON number; strings
as JSON strings). Exceptions as `{ "throws": "<simple class name>", "message": string | null }`.
- `numeric.json`: `l2i` (`[longDecimal, int]`), `f32` (`[op, aHex, bHex, resultHex]` for
  add/sub/mul/div of floats, and `d2f` casts `[dHex, fHex]`), `log10` (`[inputHex, resultHex]` for the
  double nearest 10^n, n = −323…308 (parsed from `"1e" + n`), plus `Math.pow(10, n)` inputs; only
  10^0…10^22 are exact powers, where the Javadoc requires result n),
  `divZero` (int `/` and `%`, long `/` and `%`, `Math.floorDiv/floorMod` by zero → exception row),
  `i64` (`[op, a, b, result]` for mul/add/sub/shl/shr/ushr incl. shift distances 0,1,63,64,65,−1 and
  overflow cases).
- `hash.json`: `stringHash` (`[s, int]` incl. empty, non-ASCII, surrogate pairs, long strings that
  overflow), `doubleHash` (`[hex, int]`), `doubleToLongBits` (`[hex, longDecimal]` — note canonical
  NaN vs `doubleToRawLongBits`), `integerReverse` (`[int, int]`), `kvectorHash`
  (`[xHex, yHex, int]` = `Double.valueOf(x).hashCode() + Integer.reverse(Double.valueOf(y).hashCode())`
  computed with the JDK calls — the formula is ELK's `KVector.java:155`, not JDK code).
- `text.json`: `toString` (`[hex, string]`: ~10,000 rows — every `lang.json` double, subnormals,
  `Double.MIN_VALUE`, powers of ten 1e−323…1e308, 2^n, values whose shortest decimal has length 1,
  plus seeded random bit patterns, seed recorded), `parseDouble` (`[input, hex]` accept rows and
  `[input, {throws, message}]` reject rows: whitespace/control trim, `f/F/d/D` suffix, hex floats,
  `NaN`/`Infinity` with signs, `""`, `"0x"`, `"1e"`, `"1_0"`, `"nan"`), `integerValueOf`
  (`[input, int]` / reject rows incl. `"1.0"`, `" 1"`, `"+1"`, `"2147483648"`).
- `random-setseed.json`: for seeds {0,1,−1,42}: draw a few values, `setSeed(s2)` mid-sequence
  (including after a `nextGaussian` to prove the cached value is cleared), draw again; rows record
  op and result as in `random.json`.

## Acceptance criteria
- Given the extended generator, when `java tools/vectors/JavaVectors.java test/golden/refs/java`
  runs, then `git diff --exit-code test/golden/refs/java/lang.json test/golden/refs/java/random.json`
  is clean.
- Given two runs, then the four new files are byte-identical (deterministic inputs, seeded randoms).
- Given `text.json`, then it has ≥ 10,000 `toString` rows including `4.9E-324` and `1.0E23`.
- Given `numeric.json` `divZero`, then each row records `ArithmeticException` with message `/ by zero`.
