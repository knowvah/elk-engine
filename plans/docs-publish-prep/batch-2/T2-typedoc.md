## Steps

1. Create the package and install; check `tools/typedoc/node_modules/typescript/package.json` is 6.0.3 and the root
   `node_modules/typescript` is still 7.0.2.
2. Run `npm run docs:api`; journal the error count (must be 0, else stop 7) and warning count; list the warning kinds.
3. Run `npm run docs:build`; it must pass `assertLocaleComplete` with `reference/` excluded, and
   `npx vitest run test/docs` must pass unedited.
4. Time `docs:build` before and after; journal both.

## Acceptance criteria

- Given a clean checkout after `npm ci`, when `npm run docs:api` runs, then it installs `tools/typedoc` and writes
  `docs-site/reference/index.md` with 0 TypeDoc errors.
- Given the root install, when `npx tsc --version` runs, then it prints 7.0.2 (AD-6 unchanged).
- Given `git status` after `docs:build`, when listed, then nothing under `docs-site/reference/` is untracked-but-unignored.
