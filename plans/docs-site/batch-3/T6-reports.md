The site mirrors it as `docs-site/parity.md` at build time, with links rewritten to site paths
(dot-engine's `copy-reports.mjs` pattern). T5 already added the `docs:copy-reports` script and the
`.gitignore` line for the copy.

   the GitHub blob URL. Exit non-zero if the source is missing.

   rewrite; assert the generated file starts with front matter.
