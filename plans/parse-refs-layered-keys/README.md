# parse-refs-layered-keys: mission brief (issue #63)

## Objective

The J7 parse refs (`test/golden/refs/elk-parse/`) are the oracle's import→export of the four layered goldens. Both the
oracle and the TS round trip test parse a stripped copy of each golden. The strip list `STRIP_KEYS` still removes
layered's `layering.layerId` and `crossingMinimization.positionId`, a stopgap from before layered was ported
(J7 amendment 2). The maintainer ruled on #63 (2026-11-21, and on 2026-11-23 "carry the EMap reorder"):

- drop the two keys from `STRIP_KEYS` in `tools/oracle/regen-parse-refs.sh` and in `test/golden/json-roundtrip.test.ts`;
- regenerate `elk-parse` by script and journal it. The regenerated refs may differ from the old ones only by the two
  keys appearing where the input carries them, plus the EMF `BasicEMap` reorder of existing `layoutOptions` keys that
  the two extra entries cause (values unchanged);
- update `docs/architecture/elk-json.md` to say the hand-off is done;
- report the state of the corpus hand-off (`docs/conformance.md:724-730`) without changing it.

The planning probe (issue comment of 2026-11-23) found 18 reorder hunks: afdx-multicast 6, clockdrift-hierarchy 2,
crossbar-switch 8, scrambler 2. It also found that the port reproduces the new oracle output byte for byte once
`LayeredMetaDataProvider` is registered next to CoreOptions (D1). There is no production `src/` change.

Exit (#63):

- `STRIP_KEYS` is `resolvedAlgorithm` alone, in both places. The test registers layered (D1).
- The `elk-parse` refs and `_meta.json` come from `regen-parse-refs.sh`, and the D3 check proves the diff holds only the
  allowed differences. The script's second run is byte-identical.
- `test/golden/json-roundtrip.test.ts` is green against the new refs.
- The docs say the hand-off is done (D4), and #63 gets the corpus hand-off report.
- Queue gates 1-7 are green and journaled. There is one squashed commit on the base. `plans/roadmap.md` gains
  `## Revision <date> (parse-refs-layered-keys)`, and `.agent-notes/parse-refs-layered-keys.md` is written (or the
  journal says there is nothing novel).

**Not in this mission:** any `src/` change; any other ref; changing `docs/conformance.md:724-730` (the corpus
hand-off: report it and file a `follow-up`, D4); moving goldens (#68); the translated `docs-site/` pages (#133); any
oracle patch, `ELK_COMMIT` change, or write to `~/git/knowvah/elk`.
