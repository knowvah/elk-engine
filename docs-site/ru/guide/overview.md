# Обзор

`@knowvah/elk-engine` — точное портирование на TypeScript библиотеки [Eclipse Layout
Kernel](https://www.eclipse.org/elk) (ELK), Java-библиотеки компоновки графов. Здесь нет ни Java, ни
WASM: алгоритмы компоновки заново реализованы на обычном TypeScript и проверены относительно реализации
на Java.

::: warning Пре-альфа
Ни один алгоритм компоновки пока не портирован. Репозиторий содержит инструментарий, архитектурные документы,
каркас проверки и шимы среды выполнения Java. `src/index.ts` пока не экспортирует ничего публичного.
Порядок, в котором появятся алгоритмы, см. в [дорожной карте](/guide/roadmap).
:::

## Java — это спецификация

Исходный код Java на зафиксированном коммите ELK `8aaa3c145c2a18a38aabbc725aa3791ddc517a76` является
эталонной спецификацией. Портирование следует ей максимально близко:

- Алгоритмы не оптимизируются и не упрощаются. Если Java выглядит избыточным, избыточность сохраняется.
- Портируется каждая ветка, а границы методов сохраняются, если только TypeScript не вынуждает их изменить.
- JUnit-тесты портируются вместе с кодом, который они проверяют.
- Поведение среды выполнения Java, на которое опирается ELK (32-разрядная целочисленная арифметика, порядок
  итерации `HashMap`, последовательности `Random`), воспроизводится шимами. См. [Основы Java](/ru/guide/java-foundations).

[Правила перевода](/guide/translation-rules) перечисляют, как каждое понятие Java отображается на TypeScript.

## Проверка относительно оракула

Оракул — это ELK из апстрима, собранный из исходников в отсоединённом git worktree на зафиксированном коммите.
Результаты портирования сравниваются с результатами оракула:

- Идентификаторы, количество элементов, топология секций рёбер, количество изломов и нечисловые значения должны
  совпадать точно.
- Числовые координаты и размеры должны совпадать в пределах абсолютного допуска `1e-6`.

Отобранные результаты оракула закоммичены как эталонные golden-тесты, поэтому для запуска тестов JVM не нужна.
Полная процедура описана на странице [Соответствие](/ru/conformance).

## Публичный контракт

Публичным API станет объектная модель ElkGraph плюс фабрики `ElkGraphUtil`. ELK JSON — это адаптер ввода-вывода, а
не основная модель. Первая публикация в npm зафиксирует эту поверхность.

## Ограничения среды выполнения

- `src/` безопасен для браузера: без встроенных модулей Node, без `process.env`, только ES-модули.
- Зависимостей времени выполнения нет.
