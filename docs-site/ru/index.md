::: tip Версия 1.0
`@knowvah/elk-engine@1.0.0` доступен на npm. Все алгоритмы компоновки ELK, входящие в объём проекта, портированы и
проверены относительно ELK, собранного из исходников; результаты приведены в [отчёте о паритете](/parity), а
оставшиеся различия отслеживаются как issues. Публичный API, 72 экспорта, заморожен на версии 1.0.0, а версии
следуют semver. Начните с [раздела «Начало работы»](/guide/getting-started); что будет дальше, см. в
[дорожной карте](/guide/roadmap).
:::
