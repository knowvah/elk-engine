# API reference

Names and signatures follow the Eclipse ELK Java API they are ported from, with one exception: `layout`, an async
entry point that takes and returns ELK JSON. The exported symbols are frozen from 1.0.0 on
([docs/architecture/public-api.md](https://github.com/knowvah/elk-engine/blob/main/docs/architecture/public-api.md)).

Start with [Getting started](/guide/getting-started) for runnable examples.
