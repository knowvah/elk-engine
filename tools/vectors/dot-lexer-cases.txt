# Cases for DotLexerVectors.java (format: see that file's header). Escapes: \n \r \t \\ \uXXXX; "<null>" = null.
#   lex <family> <escaped text>            -> one tokens row, id "<family>/<nnn>" (nnn counts per family, from 001)
#   conv <rule> <op> <escaped input>       -> one converters row, id "conv/<rule>/<op>/<nnn>"
# The text of a lex row is everything after "lex <family> " (it may be empty or start with a space).
#
# Lexer families: keywords, numbers, strings, html, comments, precline, ids, punct, whitespace, lines, samples,
# boundaries. Converter rules: ID STRING INT FLOAT DotID PREC_LINE ML_COMMENT SL_COMMENT WS, and an unknown name.
